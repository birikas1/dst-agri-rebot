# 孔数上限与固定工作中心

日期：2026-10-30。0.3.0-zones.2。玩家明确要求暂不使用 Claude，由 Codex 直接开发与测试。实际游戏界面按玩家要求委派同一个 GPT-6.1 Terra / xhigh 子代理。暂停 GitHub / Steam 发布，先本地测试。

## 验收规则

- 方案当前模式的选择总数不得超过田块格数 × 所选每格孔数。1 × 8 上限 8，4 × 8 上限 32。比例模式仍按比例填满。
- 加号、作物选择器、模式切换、密度变更、默认模板和服务端保存均必须遵守限制。已有超额方案保留供修改，不能静默提交；不破坏现有作物。
- 服务端用当前登记的田块格数及提交密度校验，不能信任客户端容量或暂时受阻的可用孔数。
- 建造预览随鼠标显示工作范围；固定中心标记显示创建工作组时的建造位置，鼠标悬停显示实际范围。
- 保留现有工作组共享规则；机器人移动、主机器人变更及读档不得改变中心；更新半径后同步显示。最后一个成员移除时清理标记，读档不产生重复标记。
- 客户端仅绘制范围，不依赖服务端组件；专服可载入；不得污染玩家存档或加入测试脚本。

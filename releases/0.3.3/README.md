# 0.3.3 发布说明

去掉机器人面板里已多余的种植模板编辑，并让机器人自动捡起工作范围内地上的工具。

同时包含 0.3.2 的工作中心放置与范围圈重做（0.3.1 在实机中未达标，已被取代）。

## 本版变化

- 机器人面板「管理」页去掉默认比例模板和每格孔数编辑。种植方案只在农田上方的浮动标签里设置。
- 机器人会自动捡起已绑定工作中心范围内地上的园艺锄、铲子、锤子、斧头、镐子和水壶并使用；同类已有一件时，多余的放入农业仓库。
- 工作中心改为单独制作（木板×1，原版小木牌外观）。必须先放置中心，再在其范围内放置机器人；不再自动生成中心。同一中心可有多台机器人。
- 鼠标悬停中心，或放置中心/机器人时，显示与原版雪球发射器相同的地面范围圈。

# 0.3.0 正式版 · 2026-11-01

汇总0.3.0-zones.1至zones.4的功能，更新原Steam条目，不创建重复Mod。

## 新增与修复

- 四向相连田区、独立比例/精确方案、箱子式浮窗、孔数输入上限。
- 固定工作中心、悬停与建造范围显示，客户端逐帧更新圆环。
- 仓库67槽，五类工具各3格、水壶3格，机器人按需实际取用。
- 新建筑水井，独立生成模型贴图与图标；取空壶→井边补水→返回浇田，建井恢复无水源停工。
- 机器人本体图标、羊群宝箱图标及客户端外观资源接入。
- 修复农活穿插、仓库种子只存不取、部分缺货阻塞当前播种及暂停田区占用公共库存。
- 旧仓库1–49槽编号保留，追加50–67槽；旧全局方案迁移为默认配比模板。

## 验证范围

44个生产Lua文件、20组回归通过。原生引擎完成工具/空壶提取、井边补水、真实播种浇水、建筑与仓库存档恢复检查。最终动态皮肤像素和本轮图形截图未做独立验收，第三方Mod组合不作全部兼容承诺。

## 安装

下载同目录agri_robot-0.3.0.zip，将agri_robot文件夹解压到游戏mods目录，重启并启用。主机和客户端均需安装。升级前备份存档，农田仍需手动开垦。
